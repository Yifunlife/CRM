# 安装页面保存后自动同步 · 2026-11-08

「安装前待确认」「安装工期计划」继续使用同一份安装计划。各填写阶段、表格行及日历弹窗保存成功后，通知当前页面和同源其他标签页重新读取授权数据；项目档案的师傅与工期也自动更新。通知仅含变更标识，不传递业务资料。

可见页面每15秒检查一次其他浏览器或设备保存的变更，切回页面时也自动读取。保留当前月份、筛选和滚动位置；后台更新不重建表单。填写中、表格有修改或日历弹窗打开时延后更新，保存或取消后补上。并发版本冲突保留本地修改，取消后自动加载最新资料，不再把失败保存当成成功刷新。
