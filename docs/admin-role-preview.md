# 全角色只读验收

供已启用且完成初始密码设置的管理员、CEO 核对其他人员的页面与权限。按实际人员进入，不修改被验收账号的角色、权限、市场、客户归属或密码。管理员可选择其他启用人员；CEO 不可选择管理员。查看本人请退出验收。

## 使用

1. 使用本人管理员或 CEO 账号登录，点击内容区的「全角色验收」。
2. 在按角色分组的「验收人员」下拉框中选择具体人员，核对姓名、用户名及范围说明，点击「进入只读验收」。
3. 核对浅蓝提示中的所选人员、角色及「实际登录」姓名，再检查菜单与数据。页面按所选人员现有权限、业务市场和归属读取，不额外补齐权限。
4. 需要更换对象时点击「切换人员」；完成后点击「退出验收，返回本人」，一次操作返回本人工作区。

每次验收有效 30 分钟。过期、目标停用或删除、操作者失去验收权限等情况会阻断业务页面并显示原因；可退出后重新选择。目标尚未完成初始密码设置时，只能核对账号状态，不能进入业务页面。

## 已实现并验证的安全边界

- **业务只读**：前端拦截保存等写操作，服务端独立拒绝保存、发送、授权、审批及其他业务写请求；数据库读取另有只读保护。部分原有按钮仍可见，点击不代表允许执行。
- **读取仍受原权限约束**：沿用所选人员真实的权限、市场、客户归属及跟单范围；受限页面或资料继续拒绝访问。全库备份、连接桥接与授权回调等入口不供验收使用。
- **实际操作者可追溯**：提示区显示真实登录人；开始、切换、退出及拒绝操作的审计关联真实操作者。验收审计本身会写入，业务只读不等于系统完全零写入。
- **会话隔离**：验收绑定当前真实登录会话；旧验收上下文请求会被拒绝。进入、切换或退出后刷新工作区，并通知同源的其他已打开标签页刷新；退出登录会清除验收状态。
- **连接信息保护**：相关连接状态响应不返回扫码二维码或云端验证令牌；不能在验收中发起连接或授权。
