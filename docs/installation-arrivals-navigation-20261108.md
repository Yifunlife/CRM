# 安装到货批次与导航 · 2026-11-08

## 用户要求与结果

- 左侧项目管理导航调整为「项目进度 → 安装前待确认事项 → 安装工期计划」。独立待确认事项直接打开原填写确认总表；原「订单安装计划」的可见名称统一改为「安装工期计划」。旧路由键保留，旧收藏地址继续有效；两个安装页面分别选中自己的导航。
- 撤下原主页面的项目下拉框及五按钮填写区域，不再用整块入口面板隐藏总表；安装工期计划页首保留紧凑的直接进入按钮。
- 到货与签证表单增加可重复到货行，明确显示「共 X 批货」「第 N 批」以及每批预计到货日期。可补充货物／柜数说明、实际到货日期；尚未登记总批数或日期时显示待登记／待确认，不推定日期或到货。
- 签证类型为「落地签、旅游签、商务签、工作签」四项下拉。已有「国内订单」或其他非标准旧值单独保留为原记录选项，打开及保存其他资料不暗中改签证类型。

## 数据与权限

到货批次存于现有安装计划事件的可选 `arrivals` 数组（稳定行ID、说明、预计日期、实际日期）。不执行数据库迁移、不重导项目、不改写合同、生产／装柜／发货批次或财务记录。原整单计划及实际到货记录保留，可在原资料和「原到货记录与说明」查看。旧客户端省略批次数组时不清空已存批次；同项目档案、列表及日历共享规范安装计划。

继续使用原商务维护权限、归档锁、实际操作人和版本检查。最多50批，检查批次ID唯一及有效日期。草稿可保存未定预计日期；正式确认已登记批次时需补齐每批预计日期。批次数或到货时间变更按原商务资料变更处理，已有行程需要重新确认；未保存增减行受原离开保护，取消不写入。
