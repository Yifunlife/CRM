# 到货与签证紧凑排版 · 2026-11-08

用户反馈批次不明显、页面列宽与间距不齐。本次仅调整到货与签证填写页：桌面共用一行批次表头，三列输入框统一顶边及高度，批次序号使用蓝底白字。新增按钮使用原 Fluent 主操作蓝色并放在总批数旁；增加后直接定位新批次并聚焦货物说明。

下方签证、时长、购票方和跟进日期同排；机场、接待方和费用下一排，减少孤立字段和留白。确认项桌面并列，手机保留逐行触控。手机批次仍显示完整标签，无横向溢出。数据结构、权限、确认规则和保存后自动同步不变。
