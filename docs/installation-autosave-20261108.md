# 安装准备资料自动保存

“安装要求”“师傅与工期”“到货与签证”的资料在停止输入约700毫秒后保存进度，不再需要先点保存按钮。增加、移除到货批次以及修改每批货物说明、预计/实际到货日期同样自动保存，日期可留空。切换环节、返回总表、返回工期计划、切换菜单和站内浏览器后退会先等待未完成的保存。

工厂人员交接、客户及出行准备、出票、安装完成和客户验收继续由原确认动作完成。自动保存复用 `profile`、`factory-draft`、`client-save`，不自动确认或出票，沿用现有权限、字段校验、商务/工厂确认失效规则、归档锁和版本检查。后两环节的正式登记保持原方式。

输入在保存期间仍可继续。请求按次序处理，后输入的内容不会被前一个请求的响应清除；输入框不会因自动保存重新创建。成功保存后更新本项目与共用安装记录，并沿用原跨页面同步信号。

请求失败时保留当前表单与批次草稿，提示重试，并阻止丢失当前修改的跳转。写入成功但读取失败会保留已写版本以供重试；读取到另一人刚写入的新版本时不会借该版本继续覆盖。客户档案等其他手工编辑入口继续保留原离开保护。

验收使用隔离 SQLite 与真实 CRM、真实安装接口：连续输入、慢速保存期间输入、部分资料/未知到货日期、切换环节、返回、菜单、浏览器后退、网络失败、写入后读取失败、并发修改、手机和正式确认边界。安装权限、归档、原确认流程及多批到货回归用例沿用。
