# 安装填写与跟进 · 2026-11-07

## 变更

- 项目管理仍只有「项目进度」「订单安装计划」两个导航。订单安装计划中的「进入填写总表」打开内部独立页面「安装填写与跟进」。
- 总表每行一个项目、每列一个环节，显示填写项数和独立的确认状态；表头标出维护／确认角色。项目序号与现有时间表一致，合同号仅在有值时显示于项目名下。
- 点击状态进入原安装表单；草稿实时显示已填、空白及未保存状态，空白项可定位到字段。计数包含按需项，不代表所有字段都必须填写，也不代替确认。
- 保留实际工厂确认、商务准备、出票与验收的权限、版本及凭据检查。确认人和时间读取现有事件，不受最近20条变更记录窗口限制；已失效的确认不显示旧确认时间。
- 「取消修改」不发出保存请求，清除当前未保存内容并回到总表顶部；进入表单同样回到顶部。未保存时保护阶段切换、页面导航及刷新。
- 沿用当前浅色 Fluent 外壳，采用紧凑表行、桌面多列表单、手机单列表单和表内横向查看；不增加侧栏或大面积颜色面板。
